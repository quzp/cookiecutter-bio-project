# manuscript/notes/

Thinking before and around the prose — material you write for yourself, not for readers.

Suggested files:

```
notes/
├── storyline.md          main finding in one sentence, then one line per figure
├── figure_plan.md        each figure: question, panels, key comparison, source in results/
├── outline.md            section-by-section bullet outline of the argument
└── parking_lot.md        paragraphs cut from drafts that may return
```

Write the one-sentence main finding and the storyline before the first draft, and
revisit them at each new major version: if the storyline has changed, the abstract and
discussion probably need to change too.

Literature notes belong in `management/docs/literature/`; notes here are about this
manuscript's argument.
