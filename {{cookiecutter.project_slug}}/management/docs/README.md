# management/docs/

Written material related to the project but not part of the manuscript:

```
docs/
├── literature/       Paper notes, one file per paper, with the DOI
├── meetings/         Meeting and discussion notes, YYYYMMDD_topic.md
└── methods/          Method surveys, tool comparisons, rationale for parameter choices
```

Pair `literature/` with Zotero: Zotero holds the PDFs and metadata, while these notes
hold **your judgement** — why a paper matters, whether its conclusion holds up, and how
it relates to this project.
