# docs/

项目相关的文字材料，但不属于手稿本身：

```
docs/
├── literature/       文献笔记，一篇一个 .md，注明 DOI
├── meetings/         组会与讨论记录，YYYYMMDD_主题.md
├── methods/          方法学调研、工具选型对比、参数依据
└── grants/           与本项目相关的基金申请片段、进展报告
```

文献管理建议配合 Zotero：`docs/literature/` 存的是**你自己的判断**
（这篇为什么重要、结论能不能信、和本项目什么关系），PDF 和元数据交给 Zotero。
